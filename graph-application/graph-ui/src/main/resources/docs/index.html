MonGraphe

1. Présentation

MonGraphe permet de charger et visualiser des graphes à partir de deux types de sources :

  • DOT : le graphe existe déjà dans le fichier ;
  • CSV : le graphe est construit à partir des données tabulaires.

L'application calcule ensuite une disposition spatiale des nœuds et propose plusieurs réglages de visualisation, de détection de communautés et d'export.

2. Ouvrir un fichier

Depuis le menu principal, utilisez Fichier > Ouvrir puis choisissez un fichier .dot ou .csv.

Les fichiers DOT et CSV n'utilisent pas la même logique : DOT charge directement un graphe existant, alors que CSV construit le graphe à partir des lignes du tableau.

3. Utiliser un fichier DOT

Avec un fichier DOT, les nœuds et les arêtes sont déjà définis. L'application lit la structure du fichier, initialise le graphe puis calcule sa spatialisation.

Ce mode est le plus direct si vous disposez déjà d'un graphe structuré.

4. Utiliser un fichier CSV

Avec un fichier CSV, chaque ligne du tableau est d'abord interprétée comme un nœud potentiel. L'application compare ensuite les lignes entre elles avec une mesure de similarité.

Construction du graphe

  • si deux lignes sont suffisamment proches, une arête est créée ;
  • si elles sont très éloignées, une anti-arête peut être créée ;
  • sinon, aucune relation n'est ajoutée.

Seuils

Deux seuils sont utilisés :

  • seuil d'arête : minimum à atteindre pour créer une arête ;
  • seuil d'anti-arête : maximum pour créer une anti-arête.

Vous pouvez soit saisir vos propres seuils, soit utiliser les valeurs recommandées calculées automatiquement.

5. Paramètres principaux

Dimensions

Les dimensions définissent l'espace de visualisation du graphe. Des valeurs plus grandes donnent plus de place à la spatialisation.

Communautés

Vous pouvez lancer une détection de communautés pour regrouper les nœuds selon leur structure de connexion.

K-means

Dans certains cas, un partitionnement supplémentaire peut être utilisé pour organiser plus grossièrement les regroupements.

Lambda

Le paramètre lambda intervient dans certains modes de calcul de communautés. Il influence la manière dont les groupes sont séparés.

Tooltips

La plupart des paramètres importants affichent une aide au survol afin de rappeler leur rôle directement dans l'interface.

6. Interactions dans la vue

  • Molette : zoom
  • Clic droit + déplacement : déplacement de la caméra
  • SPACE : pause / reprise
  • SUPPR ou Retour arrière : suppression du sommet sélectionné
  • Les outils Run, Select, Move et Delete modifient le comportement des interactions souris / clavier.

Les outils de sélection, déplacement et suppression dépendent de l'état de l'espace de travail courant.

7. Raccourcis clavier

Les raccourcis suivants ont été ajoutés pour rendre l'utilisation de l'application plus directe.

  • Ctrl + O : ouvrir un fichier
  • Ctrl + W : fermer l'espace de travail
  • Ctrl + Q : quitter l'application
  • Ctrl + Z : annuler
  • Ctrl + Y : rétablir
  • Ctrl + Shift + Z : rétablir
  • Ctrl + + : zoom avant
  • Ctrl + - : zoom arrière
  • Ctrl + 0 : réinitialiser la vue
  • F1 : ouvrir cette documentation
  • F11 : basculer en plein écran
Les raccourcis de zoom, d'annulation et de rétablissement sont aussi pris en charge lorsque le focus est sur le panneau OpenGL.

8. Prévisualisation et exports

Prévisualisation

Le panneau de prévisualisation permet de modifier certains paramètres visuels, par exemple l'épaisseur des arêtes ou leur affichage sous forme de courbes.

Export PNG

L'export PNG produit une image raster, c'est-à-dire une image finale composée de pixels. Ce format est adapté pour une insertion rapide dans un document ou une présentation.

Export SVG

L'export SVG produit une image vectorielle. Les objets du graphe sont décrits géométriquement, ce qui permet un redimensionnement sans perte de qualité.

9. Conseils

  • Commencez avec des seuils recommandés lorsque vous chargez un CSV.
  • Si le graphe est trop dense, réduisez le nombre d'arêtes conservées.
  • Si la vue paraît trop serrée, augmentez les dimensions de l'espace de travail.
  • Utilisez le panneau de prévisualisation avant export pour ajuster le rendu final.
